RECORD AND RUN
1. Copy attempt-ledger.csv to your working folder. It has a header only.
2. Add one row per actual attempt. Use a stable result_id for retries and a unique
   attempt_id within each result. Keep execution order within each result.
3. outcome must be accepted, rejected or error. An accepted attempt closes that
   result; do not add later attempts for it. Pending is not a CLI outcome.
4. Fill all four cost columns with nonnegative plain decimal amounts. Explicit
   zero means known zero. A blank cost means unknown and is rejected.
5. Include rejected and error attempts, not only accepted ones. Read the full
   README field limits before importing data. Do not copy fictional sample rows
   into a real experiment.
6. Run the README command on your private file. The CLI totals caller-recorded
   costs and labels; it does not check the truth of the acceptance judgement.
