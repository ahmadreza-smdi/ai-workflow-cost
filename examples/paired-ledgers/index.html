Read the cost beside the accepted result

By Ahmadreza Samadi · Start with the decision.

This offline kit accompanies the existing AI workflow cost ledger. Every example is fictional and AI-assisted. Educational, not financial advice.

1. Extract the entire ZIP

Keep the folders together. Open a terminal in the extracted folder containing compare_ledgers.py. Python 3.10 or newer must already be available; the kit needs no other packages, account, API key or network connection. Use python instead of python3 where appropriate.

python3 -B compare_ledgers.py examples/paired-ledgers/fictional-manual.csv examples/paired-ledgers/fictional-ai.csv --task "Fictional paired review" --criterion "Fictional evidence rule" --currency USD

The command reads the two example files and prints a JSON report. It does not edit them or select a winner.

3. Run the included checks

python3 -B -m unittest discover -s tests -v

The eight included checks exercise fictional paired inputs, retries, unmatched results, invalid costs, null versus zero, labels, file preservation, ordering and decimal amounts. Passing them does not verify a real result's quality or an experiment's fairness.

4. Use private copies for your own records

Use two separate CSVs with exactly the same recorded result IDs. Keep the task, population, period, acceptance rule, currency and cost allocation consistent. Matching IDs alone does not establish those facts. Keep all retries and failures. All four cost columns are mandatory: a blank is unknown, not zero. No accepted results gives undefined unit cost (null), separately from an explicitly known zero cost.

Replace the example paths and quoted labels in the command. The currency argument is a label, not conversion or ISO validation. Private task and criterion labels appear in the report; keep private records and reports out of the public repository. The helper uses ordinary temporary local snapshots, which are removed on exit; it provides no encryption or secure deletion.
